# CLAUDE.md (public docs repo)

This repo holds SwitchBord's **public** docs only: what SwitchBord is, the API contract, MCP setup, `llms.txt` and runnable examples. It is generated from the `public/` folder of a separate private repo and overwritten on every publish.

- **Don't edit here.** Changes made directly in this repo are lost on the next publish. Make them in the private repo's `public/` folder.
- **Product in one line:** SwitchBord is a free, live router for paid agent APIs (x402, MPP). It returns the best sellers for a task, checked live, plus backups. Agents pay sellers directly; SwitchBord never touches money.
- **Rules for anything written here:** describe only what the live API does today ([API.md](API.md) is the contract). Never claim SwitchBord processes payments, guarantees sellers, or ships a paying client. No secrets, infrastructure details, internal plans or ranking internals.
