# Examples

None of these pay anyone. They ask SwitchBord who to call; paying the seller is up to your agent's own x402 or MPP client.

| File | What |
|---|---|
| [route.sh](route.sh) | `curl` the router for a task and print the top candidates (needs `jq`) |
| [find-route.mjs](find-route.mjs) | Same in Node 18+, no dependencies: `node find-route.mjs "search the web"` |
| [mcp-tools-list.sh](mcp-tools-list.sh) | List the MCP server's tools over plain HTTP |
| [mcp.json](mcp.json) | MCP client config |
