# Reporting a problem

- **Security issue** (something that could hurt users or let someone abuse the service): use GitHub's private vulnerability reporting on this repo ("Security" tab → "Report a vulnerability"). Please don't open a public issue.
- **Wrong or broken result** (a seller ranked high that is down, a bad price, a broken link): open an issue with the task you asked for and what came back.

SwitchBord never holds funds or keys, so it can't move your money. Never send anyone a wallet key.
