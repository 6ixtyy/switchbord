// FAQ

What is SwitchBord?

SwitchBord is a free, live router for paid agent APIs. An AI agent asks for a task in plain words, and SwitchBord returns the sellers that are working, cheapest and fastest right now, checked live just before it answers, plus backups.

Which payment protocols does it cover?

x402 and MPP (Machine Payments Protocol) today. The inventory is 33,000+ paid endpoints from Coinbase Bazaar (x402) and mpp.dev (MPP), grouped into markets of interchangeable sellers. SwitchBord is neutral about how agents pay: each protocol is a separate source, so new ones can be added without changing how sellers are ranked.

Does SwitchBord handle payments?

No. The agent pays the seller directly with its own wallet and x402 or MPP client. SwitchBord never holds, moves or signs for funds.

How do I connect an agent?

Add the MCP server https://api.switchbord.xyz/mcp (streamable HTTP, no auth) or call GET https://api.switchbord.xyz/route?task=search%20the%20web. No signup, no keys.

Is it open source?

Yes, MIT licensed: github.com/6ixtyy/switchbord. See also llms.txt.
